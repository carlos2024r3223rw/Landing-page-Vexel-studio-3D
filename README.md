# VEXEL Studio: 3D Visualization Concept

A bilingual English/Spanish portfolio landing page for a conceptual 3D visualization studio. It showcases architectural, interior, and product imagery with a responsive layout and a local project brief demo.

[View the live page](https://carlos2024r3223rw.github.io/Landing-page-Vexel-studio-3D/)

## Features

- EN/ES language switch, with the preference saved in browser storage.
- Before/after comparison with a keyboard-accessible slider. The "before" view is a **visual wireframe effect** over the same render, not a separate modeling export.
- Service and selected-work sections featuring the included imagery.
- Three-step project brief demo: choose a project type, select deliverables, and review a summary.
- Responsive navigation and reduced-motion support.

This is a **portfolio concept**. The studio, project examples, and project brief are illustrative. The form creates a summary only in the browser. It does not collect contact details, send requests, or generate a real quotation.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required. Google Fonts are loaded over the network; the fallback system font is used offline.

## Files

- `index.html`: content and interactive form markup.
- `style.css`: layouts, responsive design, and UI states.
- `script.js`: bilingual text, comparison slider, navigation, and local brief summary.
- `hero.png`, `arch.png`, `product.png`: portfolio artwork.

To change copy, edit the Spanish text in `index.html` and its English equivalent in the `english` map in `script.js`.
